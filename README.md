# 🎬 Movie Recommendation System

A simple Python-based movie recommendation system that recommends similar movies based on genre and keywords.

## 📌 Features

- Search for a movie
- Compare movie genres
- Compare movie keywords
- Recommend up to 5 similar movies

## 🛠️ Technologies Used

- Python
- CSV
- File Handling

## 📂 Project Files

- `movies.csv` - Movie dataset
- `movie_recommendation.py` - Main Python program
- `README.md` - Project documentation

## ▶️ How to Run

Run:

```bash
python movie_recommendation.py
